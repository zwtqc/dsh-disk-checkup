# 磁盘体检

在左侧边栏增加一个「磁盘体检」入口，点开后在主区域展示 C 盘的占用与可清理项，勾选后一键删除。

## 功能

- **扫描**：统计 C / D 盘容量，逐个计算可清理目录的体积
- **分类**：每项标注「直接删」或「需提权」
- **一键清理**：勾选后点按钮直接删除，完成后自动刷新并提示释放量
- **不可删除清单**：WinSxS、Windows\Installer、System32 只展示不动手

## 覆盖的清理项

| 类别 | 项目 |
|---|---|
| 临时文件 | 用户临时目录、Windows 临时目录、错误报告、崩溃转储 |
| 浏览器 | Chrome 网页/代码缓存、Edge 缓存 |
| 包管理器 | pnpm、npm 缓存 |
| 应用残留 | DSH 更新包、微信升级补丁、Chrome / DSH 旧版本目录 |
| 系统 | Windows 更新下载缓存、Windows 日志、Edge 更新缓存 |
| 已知软件 | 南京斯沃数控（x86 部分） |

## 限制

- 标记「需提权」的项目在普通权限下会失败，返回原因而不静默跳过。
- 主题沿用宿主的设计令牌，深浅色跟随 DSH 设置。
- 报告在打开面板时实时扫描，不缓存。
